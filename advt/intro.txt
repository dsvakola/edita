Edita - The Universal Text & Code Editor for Developers

Edita is a fast, clean and colourful text and code editor for students, teachers and developers. It understands more than a dozen programming languages, from Arduino C/C++ and Python to HTML, CSS, Java and 8085 assembly, and recognises them as you type. With tabs, side-by-side editing, smart auto-indent, word suggestions and elegant Dark and Light themes, Edita makes everyday coding simple and pleasant. Free and open source, developed by Vidyasagar Robotics Academy.
